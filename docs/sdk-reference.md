# SDK 参考边界

来源：用户提供的《Cruzr S2 优必选SDK二次开发文档【对外】6.24.pdf》，共148个PDF页。原PDF不进入Git。页码指PDF物理页。

- §1.2，PDF第4–6页：七自由度机械臂关节名、弧度限位；左右腕俯仰范围不同。配置采用文档范围与资产范围交集，不擅自扩大。
- §1.3，PDF第9–10页：零位坐标轴示意。当前仿真机器人根节点绕世界Z旋转90°是桌面任务布置，不是SDK坐标定义；未声称完成真机外参标定。
- §5.1.1–5.1.2，PDF第32–35页：`/mc/sdk/robot_state` 提供带名称的JointState；`/mc/sdk/robot_command` 包含JointCmd[]，MODE_POSITION=2。500Hz/0.002s是示例，非模型策略必须500Hz的证据。文档提醒不要发阶跃指令。
- §5.10，PDF第77–84页：PGC-140-50夹爪使用独立的 `/ecat/{left,right}_grip/{state,cmd}`；位置米，指令范围0–0.05m，状态含init_state、grip_state、error_code、homed。不能仅凭开口判断抓取成功。
- §5.11，PDF第85页起：提供厂商运动学库；本项目DLS IK是仿真实现，没有复制厂商二进制或宣称等价。

工程参数：物理步长0.002s、策略50Hz、位置伺服增益、阻尼、摩擦、相机位姿、夹爪双指映射均是可调仿真参数。仿真夹爪当前只开放已检查的0–0.045m几何开口，不能把它直接视为SDK pos；SDK行程与实际开口的零位、方向及比例仍需标定。

模型：沿用本地URDF转换所得的link/joint/inertia/mesh和简化碰撞体；新桌面场景、相机与执行时序由项目配置生成。没有重新从厂家URDF验证惯量转换或碰撞精度，尤其不能将简化自碰撞当作真机安全保证。
